# MAVU Estate Analyzer

A sophisticated web-based application that provides data-driven property price estimates in South African Rands (ZAR) using advanced algorithms and market analysis.

## 🏠 Features

### Core Functionality
- **Property Analysis**: Input property details and receive accurate price estimates
- **Market Data Integration**: Real-time market trends and comparable sales
- **Amenity Impact Analysis**: Understand how features affect property value
- **Confidence Scoring**: Transparent confidence levels for each estimate
- **Value Enhancement Tips**: Suggestions to increase property value

### Input Requirements
- **Location**: City and state (e.g., "Austin, TX")
- **Property Details**: Bedrooms, bathrooms, square footage
- **Additional Features**: Year built, lot size
- **Amenities**: Garage, pool, fireplace, basement, central A/C, hardwood floors

### Analysis Output
- **Price Range**: Estimated minimum and maximum values
- **Key Influencers**: Factors affecting the price estimate
- **Recent Comparables**: Similar properties sold recently
- **Market Insights**: Local market trends and statistics
- **Enhancement Tips**: Suggestions to increase property value

## 🚀 Getting Started

### Prerequisites
- Modern web browser (Chrome, Firefox, Safari, Edge)
- No additional software installation required

### Installation
1. Download or clone the repository
2. Open `index.html` in your web browser
3. Start analyzing properties!

### Usage
1. **Enter Property Details**: Fill in the required fields with property information
2. **Select Amenities**: Check the boxes for available amenities
3. **Analyze**: Click "Analyze Property" to generate estimates
4. **Review Results**: Examine the detailed analysis and recommendations
5. **Reset**: Use "Analyze Another Property" to start a new analysis

## 📊 How It Works

### Price Calculation Algorithm
The system uses a sophisticated multi-factor analysis:

1. **Base Price**: Calculated using location-specific price per square foot
2. **Room Adjustments**: Bedroom and bathroom count multipliers
3. **Amenity Multipliers**: Value increases for features like pools, garages
4. **Market Factors**: Local demand, school quality, crime rates
5. **Property Age**: Newer homes typically command higher prices
6. **Lot Size**: Larger lots increase property value

### Market Data
Currently supports major South African markets:
- Sandton, Johannesburg
- Cape Town, Western Cape
- Durban, KwaZulu-Natal
- Pretoria, Gauteng
- Port Elizabeth, Eastern Cape
- Bloemfontein, Free State

### Confidence Scoring
Confidence levels are calculated based on:
- Data completeness (missing year built, lot size)
- Market data availability
- Property size (very small/large homes have less comparable data)
- Location-specific market knowledge
